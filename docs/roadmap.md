# Roadmap Ribosome

Принцип версионирования как у Codons: маленькие версии, каждая с ченджлогом,
уроками и увеличением покрытия. Паритет путей исполнения — закон с первой
версии.

## 0.1 — фундамент
- [x] Спецификация языка (LLM.md)
- [x] API-контракт (include/ribo.h)
- [x] Парсер + чекер (parse.c, check.c): строгие ошибки с line_text, JSON
- [x] CLI: `ribo check`

## 0.2 — исполнение (выполнено, с опережением)
- [x] Эталонный интерпретатор (interp.c): все опкоды, включая F/D и память
- [x] CLI: `ribo run`, CSV-тесты (`ribo test prog.rna cases.csv`)
- [x] Лимиты как конфигурация (RiboLimits)
- [x] MEM/GLOB/импорты-capabilities в интерпретаторе (перенесено из 0.4)

## 0.3 — wasm-бэкенд
- [x] Прямая эмиссия .wasm (emit_wasm.c), без внешнего тулчейна
- [x] Харнес Node: `tests/wasm/run.js`
- [x] `ribo verify`: дифференциал интерпретатор vs V8, фолты тоже сравниваем

## 0.4 — float и память в wasm-эмиттере
- [x] F/D-опкоды + конверсии в интерпретаторе (0.2)
- [x] MEM/IGET/IPUT/MSIZE/MGROW в интерпретаторе (0.2)
- [x] GLOB/GGET/GSET в интерпретаторе (0.2)
- [x] Те же возможности в emit_wasm.c + дифференциал (0.3 — эмиттер сразу
      покрыл полный набор опкодов)

## 0.5 — лифтер
- [x] lift.c: wasm → .rna (стек → регистры, структурный контроль → LABEL/JMP)
- [x] `ribo roundtrip`: lift + lower + дифференциал против оригинала
- [x] Корпус модулей для раундтрипа: tests/fixtures (fact_iter, collatz,
      sum_arr — ручная сборка "чужого" wasm, все roundtrip-match)
- [x] GINIT покрыт: интерпретатор и wasm-эмиссия отдают одинаковое значение

## 0.6 — браузер
- [x] Сборка ядра в wasm (clang wasm32, -nostdlib, свой libc-шим, 106 КБ)
- [x] web/: редактор, check/run/lower, drag&drop lift
- [x] Панель диффа интерпретатор ↔ V8 прямо на странице (0.7)

## 0.7 — полнота MVP-арифметики
- [x] F2IU/F2LU/D2IU/D2LU, ICLZ/ICTZ/IPOP, LCLZ/LCTZ/LPOP, IROTL/IROTR/LROTL/LROTR
- [x] Лифтер: маскирование счётчика сдвигов (паритетный баг), новые опкоды
- [x] Фикстуры shiftmask.wasm, bits.wasm; дифф в веб-оболочке

## 0.8 — замыкание wasm MVP
- [x] TABLE/TELEM/DATA декларации, CALLI (интерпретатор, чекер, эмиттер)
- [x] Лифтер: таблицы, элементы, data-сегменты, call_indirect
- [x] Фикстура indirect.wasm; паритет трапов (uninitialized/oob/mismatch)

## 1.0 — замыкание круга ✅
- [x] Fuzzing лифтера (случайные модули → roundtrip): 1100 зелёных,
      пойман баг перепутанных shr_s/shr_u
- [x] LLM.md выверен по опыту реальных агентных сессий (фолт-таблица,
      все команды CLI, все декларации)
- [x] Публичная статическая страница: web/ самодостаточен, README описывает
      деплой на любой статике
