# Tests

Три слоя, по мере milestone'ов:

1. **CSV-кейсы** (0.2): `ribo test prog.rna cases.csv` — формат как у Codons:
   `arg1,...,expected` с заголовком. Эталонные программы — в ../examples.
2. **Дифференциал** (0.3): `diff_interp_vs_wasm.py` — одни входы через
   интерпретатор и через Node (V8) на эмитированном .wasm; сравниваются
   результат И исход фолта.
3. **Фаззинг** (0.3+): генератор случайных .rna в границах грамматики LLM.md;
   оба пути обязаны совпасть или оба отвергнуть программу одинаково.

Фикстуры .wasm (для lift/roundtrip, 0.5) лежат в tests/fixtures/ и
закоммичены (исключение из .gitignore).
